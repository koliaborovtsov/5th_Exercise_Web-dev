# LampStore — Интернет-магазин ламп

React-приложение интернет-магазина с каталогом товаров, корзиной, оформлением заказа и панелью администратора.

- Каталог товаров с поиском и фильтрацией по категориям
- Страница детального просмотра товара с характеристиками
- Корзина с управлением количеством и удалением товаров
- Оформление заказа с формой данных покупателя
- Swagger UI по адресу `/api/docs`

### Панель администратора
- Вход по логину и паролю с JWT-токеном
- Статистика по товарам, заказам и выручке
- Взаимодействие с товарами: создание, редактирование, удаление
- Просмотр заказов с фильтрацией по статусу
- Смена статуса заказа
- Автоматический выход при истечении сессии и выход по надобности
